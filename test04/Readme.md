# Customer Churn Prediction - Supervised Machine Learning

## Objective
To predict whether a customer will churn or not using supervised machine learning algorithms.

## Dataset
Telco Customer Churn dataset from Kaggle.

## Data Cleaning Steps
- Removed duplicate records
- Removed customerID column
- Converted TotalCharges to numeric
- Handled missing values using median
- Encoded categorical variables
- Applied feature scaling
- Split dataset into training and testing sets

## Algorithms Used
1. Logistic Regression
2. Decision Tree
3. Random Forest
4. KNN
5. SVM

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1 Score

## Conclusion
Random Forest provided the highest accuracy.
Proper preprocessing improved overall model performance.
